# 垃圾桶

本目录接收本项目中已确认废弃、过期或临时的产物，由用户定期手动清理。原 `trash/` 的历史批次已迁入这里。

每批使用 `YYYY-MM-DD/原相对路径`；若目标已存在，另建批次，不覆盖旧文件。移动前验证源和目标均在本项目内，不沿符号链接或目录联接移动项目外内容。除本说明外，垃圾桶内容全部由 Git 忽略。

主要收纳任务中临时创建、用途已结束的测试脚本、一次性验证环境、过期文档及记录。移动前确认用途和进程占用，并记录来源、目标及原因。

Cargo、npm、pnpm、node_modules、编译增量缓存及可复用构建输出等缓存类文件保持原位，无需整理。正式测试套件、持续维护的构建工具、交付包、用户数据、私有备份、模型资产和独立仓库不能仅因被 Git 忽略就归入这里。

归档不自动删除文件，也不建立自动清空任务。同盘移动不会立即释放磁盘空间；请在确认不再需要后手动清空相应批次。
